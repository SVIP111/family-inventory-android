# 家庭物资管理 · 安卓客户端

配套 [family-inventory](../family-inventory) 后端（Go 静态服务 + JSON 文件存储）的原生安卓客户端。
Kotlin + Jetpack Compose 实现，**完全复用后端现有 REST 接口**，不需要改动服务端一行代码，
可与网页端同时使用同一份数据。

- 包名：`com.family.inventory`
- 版本：`1.0.0`（versionCode 8；按需求重编版本号，新增客户端/服务器版本信息展示）
- 最低系统：Android 7.0（API 24）；目标 API 34
- 构建产物：`app/build/outputs/apk/debug/app-debug.apk`（约 12 MB）

---

## 一、快速开始

### 1. 装 APK

把 `app-debug.apk` 传到手机，允许「安装未知来源应用」后安装。
（debug 包用 Android 调试证书签名，可直接侧载；长期使用建议自行生成 release 签名。）

### 2. 首次打开

1. 在登录页填 **服务器地址**，如 `http://192.168.1.10:8080`
   （只输 `192.168.1.10:8080` 也可以，应用会自动补 `http://`；手机需与 NAS 同一局域网）
2. 点「检测服务器」，应用会调用 `/api/auth/status` 判断是否已建账号：
   - 服务器还没有账号 → 自动切到「创建账号」模式，填用户名（2–30 字符）、密码（6–64 字符）
   - 已有账号 → 直接登录
3. 登录成功后进入物品列表，顶部显示「N 件物品 · N 个位置 · N 张图片」

服务器地址和登录令牌保存在应用私有 SharedPreferences 里；
后端会话令牌存在服务端内存中，**服务重启后需要重新登录**（与网页端行为一致）。

### 界面结构

- **顶部**：仅居中显示应用名与统计行「N 件物品 · N 个位置 · N 张图片」，不再被图标挤压。
- **底部导航**：左起 位置 / 仪表盘 / **主页（放大圆形按钮）** / 标签 / 批量 / 更多；
  点主页回到物品列表并刷新；「更多」里放批量导入、服务器设置、退出登录。
- **批量模式**：底部导航临时替换为操作栏（全选 / 已选数量 / 导出二维码 / 删除所选 / 退出批量）。
- **悬浮按钮**：右下角「＋ 新增物品」。
- **扫码**：扫到本应用的二维码会直接跳到对应物品详情 / 按位置筛选；扫到普通商品条码则当作关键词搜索。

| 深色模式 | ✅ 跟随系统 | — | 两套 Material 3 配色 |

### 已知差异

- **二维码标签打印**：安卓端提供单条/批量的二维码列表（可截图、分享链接、复制内容），
  不直接调用系统打印；需要纸面标签时仍建议用网页端「打印 / 导出 PDF」。
- **CSV 模板下载**：安卓端改为「复制表头示例到剪贴板」，避免申请存储权限写文件。
- **网格/列表切换**：手机宽度有限，统一为自适应网格；平板会自动多列。
- **统计里的位置计数**按后端返回的总数显示；位置页每行的「当前列表 N 件」是当前筛选结果下的数量。

## 四、自己构建

```bash
# 1. 依赖：JDK 17、Android SDK（platform 34 + build-tools 34.0.0）
# 2. 在 local.properties 写 sdk.dir=/path/to/android-sdk
# 3. 构建 debug 包
./gradlew :app:assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

用 Android Studio 直接 `Open` 本目录也可以，Gradle 版本 8.7 / AGP 8.5.2 / Kotlin 1.9.24。

> 仓库里的 `settings.gradle.kts` 优先使用阿里云 Maven 镜像（国内拉依赖更快），
> 官方 `google()` / `mavenCentral()` 作为兜底；如在海外的网络环境可自行调整顺序。

## 五、权限与安全

| 权限 | 用途 |
|---|---|
| `INTERNET` / `ACCESS_NETWORK_STATE` | 访问自建后端 |
| `CAMERA` | 扫码录入条码、给物品拍照（点对应按钮时才申请，可拒绝；拒绝后按钮会提示去系统设置开启） |

- 局域网部署常是 `http://NAS:8080`，因此允许明文 HTTP（`network_security_config.xml`）；
  若把服务暴露到公网，请务必套 HTTPS 并收紧该配置。
- 令牌只存应用私有目录，不写日志、不导出；退出登录会调用 `/api/auth/logout` 使服务端令牌失效。
- 请求与网页端一样走 `Authorization: Bearer <token>`；`/api/qr` 与 `/uploads/` 保持公开（仅图片/二维码）。
- 应用不申请存储权限：选图、选 CSV 全部走系统文件选择器（SAF）。

## 六、出问题怎么查

- **扫码相关**：相机权限在页面层申请（不在弹窗内），相机绑定 Activity 生命周期；
  相机初始化失败时弹窗内显示具体原因，不会再直接闪退。
- **崩溃自诊断**：应用拦截了未捕获异常，会把堆栈写入私有目录；
  下次启动时弹「上次运行发生了崩溃」，点「复制并关闭」即可把堆栈发出来定位。
  卸载重装会清空该记录。
